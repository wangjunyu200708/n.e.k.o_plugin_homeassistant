# Home Assistant · Умный дом · Быстрый старт

> **Одной строкой**: у вас дома уже работает Home Assistant, а этот плагин переводит фразы вроде «включи свет в гостиной» в вызовы его service.

---

## 1. Подготовка: адрес и токен

### Найдите адрес Home Assistant

Откройте привычный веб-интерфейс HA и посмотрите на адресную строку:

- `http://homeassistant.local:8123`
- `http://192.168.1.50:8123`
- либо домен, который отдаёт ваш reverse proxy / туннель

Уберите **путь к странице** в конце, оставив только `схема://хост:порт`. Например `http://192.168.1.50:8123/lovelace/0` → `http://192.168.1.50:8123` (плагин тоже автоматически отсекает типичные фронтенд-пути, но чистый вариант надёжнее).

### Создайте долгоживущий токен доступа

1. В HA нажмите на **аватар** (в новых версиях — в левом нижнем углу)
2. Откройте вкладку **«Безопасность»**
3. Прокрутите до **«Долгоживущие токены доступа»**
4. Нажмите **«Создать токен»**, имя любое (например `N.E.K.O`)
5. **Сразу скопируйте** строку `eyJ0eXAiOiJKV1Qi...` — после закрытия окна её больше не увидеть

> Этот токен равен правам вашей учётной записи. Плагин хранит его **в зашифрованном виде**: на Windows — DPAPI (привязка к пользователю и машине), на остальных платформах — системный keychain. Если недоступно ни то, ни другое, токен остаётся только в памяти и его нужно ввести заново после перезапуска — **в открытом виде он не сохраняется никогда**. Наружу показываются только последние 4 символа. **Не** вставляйте его в чат и не делайте скриншотов.

---

## 2. Подключение

1. N.E.K.O → панель плагинов → **Home Assistant · Умный дом**
2. Введите адрес и токен
3. Нажмите **«Проверить подключение»** — появятся версия HA, число сущностей и признак администратора
4. Нажмите **«Сохранить»**

Затем один раз нажмите **«Обновить устройства»**, чтобы плагин загрузил список сущностей (дальше 60 секунд работает кэш в памяти).

## 3. Управление голосом

Просто скажите AI-компаньону:

| Задача | Как сказать |
| --- | --- |
| Питание | `включи свет в гостиной` / `выключи свет в кабинете` |
| Яркость | `яркость света в гостиной 40%` / `сделай лампу ярче` |
| Цветовая температура | `свет в спальне 3000K` / `сделай люстру теплее` |
| Климат | `кондиционер на 26 градусов` / `кондиционер в гостиной охлаждение` / `скорость вентилятора авто` |
| Шторы | `открой шторы` / `открой шторы наполовину` |
| Медиа | `громкость колонки 30` / `выключи звук телевизора` / `пауза` |
| Сцены | `запусти сцену «я дома»` / `активируй режим «ушёл»` |

**Понимание фразы выполняет диалоговая модель N.E.K.O.** Плагин сам текст не разбирает. Поэтому «наполовину» и «чуть ярче» тоже работают: модель переведёт это в `brightness: 50` или сначала спросит точное значение. Чем расплывчатее запрос, тем вероятнее уточняющий вопрос — но это лучше, чем команда не тому устройству.

## 4. Слишком много устройств?

Если дома три «света», на `включи свет` придёт ответ «совпало несколько», и ассистент спросит, какой именно:

```
Совпало 3 устройства «свет»:
1. Гостиная Потолочный светильник (light.living_room_ceiling)
2. Спальня Потолочный светильник (light.bedroom_ceiling)
3. Прихожая Точечный светильник (light.hallway_downlight)
```

**Плагин никогда не выбирает за вас** — лучше спросить один раз, чем ошибиться. Три выхода:

- **Сказать точнее**: `включи потолочный светильник в спальне` (названия зон берутся из настроек зон HA, а не придумываются)
- **Задать псевдоним**: в панели назовите `light.yeelight_ceiling_2` так, как привыкли — например «основной свет»
- **Назвать зону**: `выключи весь свет в кабинете` — ассистент сначала перечислит свет в этой зоне, а после подтверждения отправит команды по одному

## 5. Подтверждение опасных действий

Плагин делит права на три уровня риска, и **устройства повышенного риска по умолчанию не управляемы вообще**:

| Уровень | Устройства | По умолчанию |
| --- | --- | --- |
| Низкий | свет, вентиляторы, медиаплееры, сцены, обычные шторы | разрешено |
| Средний | выключатели/розетки, климат | разрешено (помечено в панели) |
| Высокий | замки, охранные панели, клапаны, водонагреватели, гаражные ворота | **заблокировано** |

Устройства повышенного риска разрешаются в панели **по одному** — «выбрать все замки» нет. И даже после разрешения каждое действие требует повторного подтверждения: разрешение решает, *можно ли* управлять, а не *спрашивать ли* перед этим:

```
> открой входную дверь
< Действие повышенного риска, не выполнено. Собираюсь выполнить "unlock" для "Замок входной двери". Код: a3f9c1d2 (действует 120 с)

> a3f9c1d2
< Выполнено: lock.unlock — обратное чтение подтверждает "unlocked"
```

Код одноразовый, привязан к «устройства + действие + параметры», при смене цели становится недействительным и истекает через 120 с. Направления, которые делают мир **безопаснее** — выключить, запереть, поставить на охрану — не задерживаются.

## 6. Нет Home Assistant? (режим знакомства)

**Плагин не содержит и не устанавливает Home Assistant.** Это осознанно: HA — самостоятельный сервис, обнаружение устройств должно происходить в его сети, а размер и темп обновлений не место внутри плагина.

Самый быстрый способ попробовать — Docker на постоянно включённой машине (NAS, мини-ПК или даже локальный компьютер):

```bash
docker run -d \
  --name homeassistant \
  --restart=unless-stopped \
  --network=host \
  -v /path/to/ha-config:/config \
  ghcr.io/home-assistant/home-assistant:stable
```

Откройте `http://<IP-этой-машины>:8123`, создайте аккаунт и выпустите токен по разделу 1. Реальные устройства не обязательны — в HA можно добавить виртуальные сущности (`input_boolean`, шаблонные лампы), и этого хватит для проверки.

> ⚠️ Нужен `--network=host`, иначе HA не сможет автоматически обнаруживать устройства в локальной сети (особенно всё, что зависит от широковещательных пакетов — Mijia/Tuya). В bridge-сети они потеряются.

## 7. Частые вопросы

**Q: Пишет «не настроено».**
A: Подключение ещё не сохранено. Введите адрес и токен, нажмите «Сохранить».

**Q: Проверка подключения падает с 401 / 403.**
A: Токен неверный или отозван. Создайте новый на странице «Безопасность» в HA. 403 обычно означает нехватку прав у пользователя.

**Q: Проверка подключения не может достучаться.**
A: Плагин работает на машине с N.E.K.O и должен достигать HA **именно оттуда**. Сначала проверьте `ping` или откройте адрес в браузере на этой машине. Если `homeassistant.local` не резолвится — используйте IP.

**Q: Управление работает, но имена зон не подхватываются.**
A: Реестры WebSocket недоступны (причина видна в `get_status`). Чаще всего пользователь токена не администратор — создайте токен от админского аккаунта. В деградированном режиме сопоставление всё равно работает по именам сущностей.

**Q: Новые устройства не появились.**
A: Нажмите «Обновить устройства» в панели. Снимок сущностей кэшируется на 60 секунд.

**Q: Поддерживаются роботы-пылесосы / увлажнители / замки?**
A: Замки поддерживаются, но относятся к повышенному риску: включайте их в панели по одному, и каждое действие всё равно проходит повторное подтверждение. Вентиляторы, клапаны, водонагреватели, охранные панели и скрипты тоже поддерживаются. Пылесосы, увлажнители и камеры пока не управляемы — плагин прямо об этом говорит, а не делает вид, что выполнил. Датчиками управлять нельзя, но их **можно опрашивать**.
